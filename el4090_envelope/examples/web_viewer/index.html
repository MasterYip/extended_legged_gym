Method note

Rejection is pinned to the chosen reference pose. Each joint is swept over its full URDF range ±3 rad with the other joints fixed; the magenta bands are where the swept body leaves the allowed envelope. The sweep animation moves a marker along each rejected interval's true foot trajectory.

MODE C · HAA REJECTION

capsule set
Method note

HAA is swept with each leg's HFE/KFE pinned at the JOINT POSE rack values. Drag HFE/KFE to move the rejection band; drag HAA to check a value — the marker rides the band (magenta = rejected, amber = accessible). When the envelope narrows, folding is the natural response: the rejection accounts for the legs folding in via HAA, so the tuck |HAA| ≳ 1.6 shows up as accessible on its own (HFE/KFE stay pinned). The envelope is convex (intersection of support half-planes) — it cannot be non-convex; the middle width only shapes it while above the corner hull (below it the shape is the corner quadrilateral).
